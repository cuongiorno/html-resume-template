# html-resume-template
Template for creating resumes in HTML/CSS

## How to use
1. Download both index.html and index.css to the same directory
2. Edit index.html to change sample data with real data (create more sections/positions by copying `<div>`s
3. Open HTML in a browser and print to PDF (no margins)
4. (optional) It is recommended to compress PDF with a tool such as Ghostscript
